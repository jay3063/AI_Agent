# A-SPICE 4.1 CL2 감사 스킬

## 전제

- **CL2 (Managed)** 는 프로세스가 "관리되고 있음"을 의미하며, **CL1 (Performed)** 이 선행 조건이다. 즉 각 프로세스의 Base Practice(BP) 산출물이 애초에 존재하지 않으면 CL2 판정 자체가 불가능하다 — 이 경우 "CL1 미달성"으로 명시하고 CL2 항목은 평가하지 않는다.
- CL2는 두 개의 프로세스 속성(Process Attribute)으로 구성된다.
  - **PA 2.1 Performance Management (성과관리)**
  - **PA 2.2 Work Product Management (산출물관리)**
- 본 스킬은 실무 감사를 돕기 위한 보조 도구이며, **VDA Scope / Automotive SPICE 공식 PAM(Process Assessment Model) 원문을 대체하지 않는다.** 공식 심사·인증·계약상 근거가 필요한 경우 반드시 원문과 대조해야 한다는 점을 보고서에 명시한다.

## 감사 절차

1. **대상 프로세스 식별**: 점검 대상 산출물이 어느 프로세스에 속하는지 분류한다 (SYS.1~5, SWE.1~6, SUP.1/8/9/10, MAN.3, ACQ.4 등). `references/work-products.md` 참고.
2. **CL1 선행 확인**: 해당 프로세스의 대표 산출물(BP 결과물)이 실제로 존재하는지 파일 시스템에서 확인한다. 없으면 추측하지 말고 "미제출/부재"로 기록한다.
3. **PA 2.1 점검**: `references/generic-practices.md`의 GP 2.1.1~2.1.6 지표별로 증거를 찾는다 (목표 정의, 계획, 모니터링, 조정, 책임/권한, 자원).
4. **PA 2.2 점검**: 같은 문서의 GP 2.2.1~2.2.4 지표별로 증거를 찾는다 (산출물 요구사항 정의, 문서화/형상통제 요구사항 정의, 식별·문서화·통제, 검토·조정).
5. **등급 부여**: ISO/IEC 33020 rating scale을 사용한다.
   - N (Not achieved, 0~15%) / P (Partially achieved, >15~50%) / L (Largely achieved, >50~85%) / F (Fully achieved, >85~100%)
   - 근거 없는 등급은 부여하지 않는다. 반드시 실제 파일 경로·섹션·문구를 인용한다.
6. **PA 단위 종합 및 CL2 결론**: 프로세스 속성별로 종합한 뒤, CL2 달성/부분달성(P/L)/미달성 여부를 결론짓는다.
7. **보고서 작성**: 아래 출력 형식을 따른다.

## 출력 형식

표:

| Process | Work Product | GP | 등급(N/P/L/F) | 근거(파일/위치) | 미흡사항 | 권고사항 |
|---|---|---|---|---|---|---|

표 다음에:
- **종합의견**: CL2 달성 / 부분달성 / 미달성
- **주요 리스크 Top 3** (조치하지 않으면 재심사·양산 심사에서 문제될 사항)
- **다음 단계 권고** (우선순위 순)

## 원칙

- 산출물이 없거나 확인 불가하면 "부재/미확인"으로 명시하고 등급은 N으로 두거나 "평가 불가"로 표시한다. 존재를 가정하지 않는다.
- 하나의 산출물이라도 실제 내용을 열어 확인한 뒤 근거로 인용한다. 파일명만 보고 판단하지 않는다.
- 보고서는 사용자가 사용한 언어(기본: 한국어)로 작성한다.
