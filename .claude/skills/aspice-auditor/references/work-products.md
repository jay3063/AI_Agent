# 프로세스별 대표 산출물 (CL1 선행 확인용)

> 프로세스 식별 및 CL1 산출물 존재 여부를 빠르게 스크리닝하기 위한 참고 목록. 프로젝트마다 명칭은 다를 수 있으니 "동등한 내용을 담은 문서가 있는가"로 판단한다.

## 시스템 엔지니어링 (SYS)

| 프로세스 | 대표 산출물 |
|---|---|
| SYS.1 요구사항 도출 | 이해관계자 요구사항 목록, 요구사항 도출 회의록 |
| SYS.2 시스템 요구사항 분석 | 시스템 요구사항 명세서, 요구사항 추적표(도출→시스템) |
| SYS.3 시스템 아키텍처 설계 | 시스템 아키텍처 설계서, 인터페이스 정의서 |
| SYS.4 시스템 통합 및 통합 테스트 | 통합 전략/계획, 통합 테스트 케이스/결과 |
| SYS.5 시스템 인수 테스트 | 인수 테스트 계획, 인수 테스트 케이스/결과 |

## 소프트웨어 엔지니어링 (SWE)

| 프로세스 | 대표 산출물 |
|---|---|
| SWE.1 소프트웨어 요구사항 분석 | SW 요구사항 명세서, 추적표(시스템→SW) |
| SWE.2 소프트웨어 아키텍처 설계 | SW 아키텍처 설계서, 동적 동작 설명 |
| SWE.3 소프트웨어 상세설계 및 유닛 구현 | 상세설계서, 소스코드, 코딩 표준 준수 기록 |
| SWE.4 소프트웨어 유닛 검증 | 유닛 테스트 계획/케이스/결과, 커버리지 리포트 |
| SWE.5 소프트웨어 통합 및 통합 테스트 | SW 통합 전략, 통합 테스트 케이스/결과 |
| SWE.6 소프트웨어 정격 테스트(Qualification Test) | 정격 테스트 계획/케이스/결과, 요구사항 대비 테스트 커버리지 |

## 지원 프로세스 (SUP)

| 프로세스 | 대표 산출물 |
|---|---|
| SUP.1 품질보증 | QA 계획, 감사/리뷰 기록, 부적합 보고서 |
| SUP.8 형상관리 | CM 계획, 베이스라인 목록, 형상항목 상태 기록 |
| SUP.9 문제해결관리 | 문제 로그, 근본원인분석, 조치 이력 |
| SUP.10 변경요청관리 | 변경요청 목록, 영향분석, 승인 이력 |

## 관리/공급 프로세스

| 프로세스 | 대표 산출물 |
|---|---|
| MAN.3 프로젝트관리 | 프로젝트 계획서, 일정/자원 계획, 리스크 관리 계획, 진척 보고 |
| ACQ.4 공급자 모니터링 | 공급자 계약/요구사항, 공급자 평가/모니터링 기록 |

## 스크리닝 체크리스트

- [ ] 산출물이 실제 저장소/문서관리시스템에 존재하는가 (파일 경로 확인)
- [ ] 산출물에 버전/승인 정보가 있는가
- [ ] 산출물 간 추적성(traceability)이 확인 가능한가
- [ ] 최신 베이스라인인지, 아니면 초안(draft) 상태인지 구분되는가
