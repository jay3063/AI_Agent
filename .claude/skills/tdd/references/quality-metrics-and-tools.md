# 품질 지표 측정 (오픈소스 도구 사용, 필수)

`CLAUDE.md`의 구현 지침에 정의된 지표를 **추측이나 육안 판단이 아니라 실제 오픈소스 측정 도구 실행 결과**로 검증한다. 도구가 설치되어 있지 않으면 설치 후 실행하거나, 설치가 불가능한 환경임을 명시하고 수동 점검 결과를 근거(코드 인용)와 함께 남긴다. 근거 없이 "기준 충족"으로 판단하지 않는다.

## 사용 도구

| 도구 | 용도 | 설치 |
|---|---|---|
| `lizard` | 함수별 순수코드라인(NLOC), 순환복잡도(CCN) 측정 | `pip install lizard` |
| `radon` | 순환복잡도 재검증, 주석/코드 비율(raw 지표) 측정 | `pip install radon` |
| `pylint` | 중복 코드 탐지(symilar 기반 `duplicate-code`), 명명 규칙 검사 | `pip install pylint` |
| `unittest` (표준 라이브러리) | 테스트 실행 및 Red/Green 확인 | Python 3.14 표준 라이브러리 |

## 1. 함수 순수코드라인 ≤ 50 / 순환복잡도 ≤ 10

```bash
lizard -l python -L 50 -C 10 <대상 경로>
```

- `-L 50`: NLOC(주석/공백을 제외한 순수 코드 라인 수)이 50을 초과하는 함수를 경고로 표시한다.
- `-C 10`: 순환복잡도(CCN)가 10을 초과하는 함수를 경고로 표시한다.
- 경고(warning)로 표시된 함수는 **반드시** 분리/리팩토링한다. 경고를 무시하고 통과 처리하지 않는다.
- 보조 검증: `radon cc -s -a <대상 경로>` 실행 결과에서 각 함수의 등급이 B(6~10) 이하인지 확인한다(등급 C 이상은 기준 위반).

## 2. 중복 코드 ≤ 7라인

```bash
pylint --disable=all --enable=duplicate-code --min-similarity-lines=8 <대상 경로>
```

- `min-similarity-lines=8`로 설정하면 **8줄 이상 동일/유사한 코드 블록**만 `R0801(duplicate-code)`로 보고된다. 즉 7줄까지의 중복은 허용 기준과 일치하며, 8줄 이상 중복이 보고되면 위반이다.
- 위반 발견 시 공통 함수/헬퍼로 추출하여 제거한다.

## 3. Doxygen 주석 비율 ≥ 20%

```bash
radon raw -s <대상 파일>
```

- 출력 필드: `LOC`(전체 라인), `LLOC`(논리 라인), `SLOC`(소스 라인), `Comments`(`#` 주석 라인), `Multi`(독스트링 등 여러 줄 문자열), `Blank`(공백 라인).
- Python에서 Doxygen 주석은 대부분 `"""! ... """` 형태의 독스트링(=Doxygen 특수 주석)으로 작성되므로 `Multi`에 집계된다. 따라서 **주석 비율은 아래 공식으로 계산한다.**

```
주석비율 = (Comments + Multi) / LOC
```

- 이 값이 0.20 미만이면 위반이다. `@brief`/`@param`/`@return`/`@throws` 태그를 포함한 Doxygen 독스트링(`references/doxygen-comment-style.md` 참고)을 보강하여 기준을 충족시킨다. 내용 없는 주석을 양만 채우기 위해 추가하지 않는다 — 실제로 설계 계약(사전/사후조건 등)을 설명하는 주석으로 채운다.

## 4. 결과 보고 형식

각 대상 파일/함수에 대해 다음을 표로 보고한다.

| 파일/함수 | NLOC | CCN | 중복(8줄↑) | 주석비율 | 판정 |
|---|---|---|---|---|---|
| ... | ... | ... | 없음/있음(위치) | ...% | Pass/Fail |

Fail 항목은 리팩토링 후 **재측정**하여 Pass로 전환한 결과까지 보고한다. 측정 없이 "기준을 만족한다"고 서술하지 않는다.
