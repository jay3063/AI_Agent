## TPL-SWE5-001 문서 통제 및 목차

문서 통제(작성 문서 ID/명칭, 버전 및 베이스라인, 작성자/검토자), 변경 이력, 작성·검토·승인 상태 표를 문서 서두에 포함한다.

1. **목적 및 적용범위**
   1.1 목적 / 1.2 적용범위 / 1.3 적용 경계
2. **통합 원칙** — 통합 단위, 단계, 위험 우선순위, 반복 가능성, 실패 격리 원칙
3. **통합 항목과 순서** — 통합 항목 ID, 선행조건, 의존성, 순서, 담당, 계획 베이스라인 (`references/coverage-and-tools.md`의 통합 순서 연계 규칙 및 `architecture-design` 스킬의 통합 순서 테이블을 그대로 이어받음)
4. **환경 및 형상** — 도구, 실행환경, SW 버전, 시험 데이터, 형상 식별 방법
5. **진입 및 종료 기준** — 각 통합 단계의 시작/중단/재개/완료 판정 기준(함수·Call 커버리지 100% 포함)
6. **통합시험 케이스 요약** — 인터페이스/통합 위험을 다루는 시험 ID, 추적 대상, 기대결과, 자동화 여부
7. **시험 설계기법** — 경계값/동등분할/의사결정표/상태전이 등 기법의 선정 근거와 적용 대상 (`references/iso26262-test-methods.md` 근거로 작성)
8. **실행 및 결과 기록 규칙** — 실행 식별자, 시각, 환경, 실제결과, 증거 위치, 결함 연결 방법
9. **회귀 전략** — 변경 영향에 따른 회귀 범위 선정, 자동 실행, 결과 비교 방법
10. **실패 및 편차 처리** — 시험 실패/환경 문제/계획 편차의 분류, 보고, 재시험, 승인 절차
11. **추적성과 보고** — 아키텍처 인터페이스, 시험 케이스, 실행 결과, 결함, 보고서 연결
12. **적용 한계** — 통합시험으로 확인하지 못하는 시스템/HIL/차량/양산 환경 범위
13. **추적성** — 입력 설계·형상, 시험 명세, 결과·결함 기록의 양방향 추적
14. **참고자료** — 아키텍처, 상세설계, 검증 계획, 환경 정의, 사용 도구 자료

## TPL-SWE5-002 통합시험 케이스 시트 (열 구성)

| 열 | 설명 |
|---|---|
| Test ID | 시험 케이스 고유 식별자 |
| Trace | 대상 아키텍처 인터페이스 ID/통합 항목 ID/요구사항 ID |
| Integration Item | 이 시험이 다루는 통합 항목(컴포넌트 조합) |
| Stimulus | 입력/자극(호출 인자, 이벤트, 결함 주입 조건 등) |
| Expected Result | 기대 결과(인터페이스 계약 기준) |
| Technique | 적용 시험 기법(`references/iso26262-test-methods.md` 어휘 사용) |
| Automation | 자동화 여부/방법 |

## TPL-SWE5-003 통합시험 결과서 시트 (열 구성)

**결과 테이블**

| 열 | 설명 |
|---|---|
| Test ID | TPL-SWE5-002의 Test ID와 동일 |
| Trace | 대상 인터페이스/통합 항목/요구사항 ID |
| Result | Pass/Fail/Blocked |
| Actual Result | 실제 결과 |
| Evidence Locator | 로그/증거 위치 |
| Defect ID | 연결된 결함 ID(있는 경우) |
| Disposition | 처리 방침(재시험/승인/이관 등) |

**실행 요약 테이블**

| 열 | 설명 |
|---|---|
| Run ID | 실행 회차 식별자 |
| Date | 실행 일자 |
| Baseline | 대상 형상 베이스라인 |
| Environment | 실행 환경 |
| Planned | 계획된 케이스 수 |
| Pass / Fail | 통과/실패 건수 |
| Overall | 종합 판정 |
| Limitation | 이 실행의 한계(적용 한계 12장과 연계) |

## 이 스킬이 목차에 추가하는 산출물

- **A-SPICE SWE.5 / ISO 26262-6 자체 점검 결과** — 문서 최종 섹션에 추가.
